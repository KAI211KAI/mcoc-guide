01 新手入门

初入《漫威超级争霸战》，最关键的并非盲目抽卡，而是先建立扎实的战斗手感与清晰的资源分配意识。下面四步，帮你平稳度过新手期。

熟悉基础战斗操作

游戏采用即时格斗操作：轻击（点按）、中击（滑动）与重击（长按蓄力）构成基础连段；左侧按住防御可格挡，向后滑动可闪避冲刺。特殊技能 SP1/SP2/SP3 由能量条驱动。新手建议先练好「格挡普攻 → 闪避重击 → 抓硬直反击」的基础循环，这是后续一切操作的基石。

优先推进主线关卡（Story Quest）

主线任务奖励稳定、内容可预期，是解锁更多玩法、章节与世界观的关键，也是前期最值得投入能量的方向。主线产出大量 ISO-8、催化剂与单位（荣耀点），难度随章节逐步提升，能自然带动主力英雄的培养。

坚持每日任务与登录签到

每日任务与每日登录奖励门槛低、收益稳定，能持续积累水晶、金币与单位等基础资源。养成「每天清日常」的习惯，长期来看是账号资源最稳定的来源之一，也是最容易被忽视的成长捷径。

集中培养 2-3 位主力

前期资源有限，与其平均分配到大量英雄，不如集中资源打造 2-3 位高星级主力，快速形成能通关主线、参与活动的核心阵容。待主力成型后再逐步扩充英雄池，能显著提升前期的成长效率。

02 资源规划

资源永远是稀缺的，规划的好坏直接决定账号成长速度。核心资源包括水晶、ISO-8、催化剂、金币、能量与单位（荣耀点），下面分项说明使用优先级。

水晶：优先投入高强度卡池

水晶是获取新英雄的核心途径，分为普通水晶（Premium）与限定 / 高强度英雄卡池。建议将单位优先用于「限定卡池」或强度被公认的新英雄卡池，而非在普通水晶上空耗，以提高出货的性价比。

ISO-8 与催化剂：理性分配给主力

ISO-8 用于提升英雄等级，催化剂（基础 / 中级 / 初级 / 职业催化剂等）用于突破星级与等级上限。两类材料都应优先供给高星级、高潜力的主力英雄，避免「雨露均沾」导致谁都练不强。

能量：先清高收益后推主线

能量（Energy）会随时间自动恢复，满能量后不再回复，等于变相浪费。建议优先级：每日高收益活动 > 限时活动 > 主线推进，尽量保持能量不长期处于满状态，最大化利用自然回复。

单位与联盟荣耀点：积攒后换关键道具

单位（Units，俗称荣耀点）可用于购买觉醒水晶、催化剂等关键道具；联盟荣耀点（Glory）建议积攒后集中购买高等级催化剂或觉醒材料。避免零散消耗，把资源用在刀刃上。

03 游戏模式

MCOC 拥有丰富玩法，覆盖单人成长与团队协作。了解各模式的定位与机制，才能把有限的时间与精力花在收益最高的地方。

STORY

主线故事

推图解锁世界观与进阶材料，是新手最核心、最稳定的成长线。难度随章节与节点递增，可反复刷取，是前期能量投入的首选方向。

EVENT

活动任务

每月轮换的限时活动（Event Quest），奖励丰厚，是获取新英雄、觉醒材料与稀有催化剂的主要来源。通常划分「普通 / 困难 / 英雄」等多档难度，量力而为即可。

ARENA

竞技场

3v3 排位对战，通过连胜积累分数，赛季结算可换取特定英雄与资源。需要合理搭配三人阵容，并利用连胜加成冲榜。

AQ / AW

联盟任务与联盟战

联盟协作推进副本（AQ）或对战其他联盟（AW），产出联盟荣耀点与高端资源。考验团队协作、出勤率与个人操作，是高端养成资源的重要来源。

BATTLEGROUNDS

战斗争霸

动态规则与禁选轮换的对战模式，考验英雄池深度与阵容理解，竞争性极强。需要熟悉规则、灵活应对不同对手与节点。

INCURSIONS

无尽竞技场

多轮层层递进、状态与减益持续累积的挑战玩法，适合检验队伍整体强度与续航。可单人也可组队，奖励与轮次深度挂钩。

04 进阶技巧

度过新手期后，想要在高难度内容中走得更远，除了英雄星级，更需要理解机制的深度。以下四条进阶思路，帮你真正拉开差距。

理解职业克制与觉醒能力

六大职业存在克抑制关系：宇宙 → 科技 → 变异 → 格斗 → 科学 → 神秘 → 宇宙，克制时输出与减伤都有加成。同时「觉醒能力（Signature）」往往是英雄质变的关键，尽量为核心主力觉醒，优先级高于堆砌更多英雄。

善用特殊技能连段

特殊技能不要无脑释放，应衔接在对手倒地、眩晕或重击硬直之后，让伤害最大化；同时管理能量条，避免满能量继续挨打而溢出。合理留 SP2/SP3 反打，是高手与普通玩家的分水岭。

根据对手灵活调整阵容

出战前观察对手职业、技能机制与关卡节点（Node）规则，选择能克制或规避其机制的英雄，往往比单纯堆数值更有效，是打通高难度内容的胜负手。

关注版本动态

关注英雄平衡调整、新英雄上线，以及遗物（Relic）、升华（Ascension）等新系统，及时调整培养方向，避免把资源投给即将削弱的对象或过时路线。
